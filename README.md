# Эмулятор оболочки ОС (Вариант №6)

Учебная практическая работа по дисциплине «Конфигурационное управление».

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС.
На данный момент реализованы 1 и 2 этапы: создание GUI-интерфейса, 
парсер с раскрытием переменных окружения, команды-заглушки (ls, cd, exit), 
а также чтение параметров командной строки (--vfs, --script) и 
выполнение стартовых скриптов с поддержкой комментариев.

## 2. Функции и настройки

### Команды
| Команда | Описание |
|---|---|
| `ls` | Заглушка. Выводит имя и аргументы. |
| `cd` | Заглушка. Выводит имя и аргументы. |
| `exit` | Завершить работу. |

### Параметры командной строки
| Параметр | Обязателен | Описание |
|---|---|---|
| `--vfs <путь>` | Нет | Путь к физическому расположению VFS. |
| `--script <путь>` | Нет | Путь к стартовому скрипту. |

### Стартовый скрипт
Формат — текстовый файл. Поддерживаются комментарии (`#`). 
Если в скрипте встречается ошибочная команда, выполнение скрипта останавливается.

## 3. Запуск
Из корневой папки проекта:
```bash
py -m src.main
py -m src.main --vfs tests/data/vfs_minimal --script scripts/start.txt
